# 用户画像分析技能

## 功能概述

这是一个专业的电商用户画像分析技能，能够对电商客户数据进行深度分析，识别用户群体特征，预测消费行为，并提供精准营销策略建议。

## 核心能力

- **RFM分析**: Recency(近期性)、Frequency(频率)、Monetary(金额)三维用户分群
- **用户价值分析**: 基于收入-消费比的用户价值矩阵分析
- **行为模式识别**: 产品偏好、购买频率、生命周期阶段分析
- **智能分群**: 自动识别7大核心用户群体
- **可视化报告**: 生成专业的用户画像分析图表和报告

## 使用场景

当您需要分析以下内容时，本技能会自动激活：

- 电商用户画像构建和客户分群
- RFM模型分析和客户价值评估
- 消费行为模式识别和产品偏好分析
- 用户生命周期管理和流失预警
- 营销策略制定和个性化推荐
- 客户细分和精准营销方案设计

## 分析流程

### 1. 数据准备
```python
# 数据文件格式要求
# 必需字段：用户ID、年龄、性别、收入、消费金额、购买频率、注册时长、最近购买产品
# 数据文件：CSV格式，UTF-8编码
```

### 2. RFM分析
```python
# R (Recency): 注册时长分析 - 新用户/活跃/稳定/老用户
# F (Frequency): 购买频次分析 - 低频/中频/高频
# M (Monetary): 消费金额分析 - 低价值/中价值/高价值
```

### 3. 用户群体识别
- 年轻护眼刚需族 (18-27岁 + 护眼产品)
- 高收入美妆爱好者 (高收入 + 美妆产品)
- 中年视力关爱群体 (28岁+ + 护眼产品 + 视力问题)
- 价格敏感学生党 (年轻 + 低收入 + 低消费)
- 忠诚高价值用户 (长期活跃 + 高消费)
- 新兴潜力用户 (新注册 + 高收入潜力)
- 流失风险用户 (老用户 + 低频购买)

### 4. 可视化分析
- 用户分群分布图
- 消费行为特征图
- 产品偏好热力图
- 年龄-性别交叉分析
- 收入-消费散点图

## 快速开始

### 基础分析
```python
# 运行完整用户画像分析
python scripts/user_segmentation.py --data your_data.csv

# 仅进行RFM分析
python scripts/rfm_analysis.py --data your_data.csv

# 生成可视化报告
python scripts/visualization.py --data your_data.csv --output reports/
```

### 自定义分析
```python
# 调整RFM分群阈值
python scripts/user_segmentation.py --data your_data.csv \
    --r-thresholds 3,6,9 \
    --f-thresholds 3,5 \
    --m-thresholds 100,200
```
